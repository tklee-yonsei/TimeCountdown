# 카운트다운 타이머

간단하고 사용하기 쉬운 웹 기반 카운트다운 타이머 애플리케이션입니다.

## 기능

- 시간, 분, 초 단위로 타이머 설정
- 타이머 시작, 일시정지, 초기화
- 타이머 제목 사용자 지정
- 라이트/다크 테마 전환

## 사용 방법

1. 시, 분, 초 입력 필드에 원하는 시간을 설정합니다.
2. "시작" 버튼을 클릭하여 카운트다운을 시작합니다.
3. 필요한 경우 "일시정지" 버튼을 클릭하여 타이머를 일시정지할 수 있습니다.
4. "초기화" 버튼을 클릭하여 타이머를 초기화할 수 있습니다.
5. 하단의 입력 필드에 원하는 제목을 입력하고 "변경" 버튼을 클릭하여 타이머 제목을 변경할 수 있습니다.
6. "다크 모드" 또는 "라이트 모드" 버튼을 클릭하여 테마를 전환할 수 있습니다.

## 기술 스택

- HTML5
- CSS3
- JavaScript (바닐라)
